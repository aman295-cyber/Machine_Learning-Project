### 3. Car Price Prediction

Predicting car prices using Machine Learning.

**Dataset Features**
- Levy
- Manufacturer
- Production Year
- Category
- Leather Interior
- Fuel Type
- Engine Volume
- Mileage
- Cylinders
- Gear Box Type
- Drive Wheels
- Airbags

**Models Used**
- Linear Regression
- Log Linear Regression
- Random Forest Regressor

**Best Model:** Random Forest Regressor performed best after data cleaning and outlier removal.

**Evaluation**
- MAE: Approximately 3934
- R² Score: Approximately 0.77
